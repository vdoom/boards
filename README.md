# Firmware, software and documentation for maker boards

[Українська](README.uk.md)

Small boards for makers. Each board is sold on its own; everything needed to use it, including source code, is here for free. Every product has its own folder.

Product pages: https://vdoom.github.io/boards/

## Downloads

Ready-made files (firmware images, Windows apps, STL files) are on this repository's **Releases** page. Each release name starts with the product's folder name, for example `ins10-a3-v1.0.0`, so type the folder name into the release search to see one product's files.
