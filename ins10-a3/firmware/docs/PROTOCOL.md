# Протокол USB-консолі

Прошивка `ins10_ahrs` спілкується текстовими рядками через USB CDC. Швидкість порту значення не має; термінал має виставити DTR. Той самий протокол використовує інструмент [tools/ins10.py](../tools/ins10.py).

- Команда — один рядок, що закінчується `\n` або `\r`.
- Відповідь — нуль або більше рядків, а потім рівно один рядок `OK` або `ERR <причина>`.
- Рядки з `#` інформаційні. У них зручні для розбору пари `ключ=значення`.
- Рядки з `$` — записи потоків. Вони можуть з'являтися між рядками відповіді.

Якщо ПК не встигає читати, прошивка відкидає вивід, але не зупиняє цикл сенсорів.

## Команди

| Команда | Дія |
|---|---|
| `help` | Перелік команд |
| `info` | Версія, плата, стан сенсорів, джерело такту і частота IMU, масштаби сирих даних, поточні потоки, причина останнього перезапуску (`last_reset=watchdog` означає, що головний цикл завис), прапорці калібрування |
| `status` | Прапорці фільтра, кути, сигми, зсув гіроскопа, прискорення, поле, температура, барометр, лічильники справності сенсорів і фільтра (спрацювання сторожа, відкинуті вибірки, перезапуски), завантаження процесора |
| `stream att <гц>` | Частота записів `$ATT`, 0–200. 0 вимикає |
| `stream raw <n>` | Записи `$RAW`: сума `n` вибірок IMU на рядок, 1–1024. 1 — кожна вибірка, 0 вимикає |
| `stream mag <0\|1>` | Записи `$MAG` |
| `stream baro <0\|1>` | Записи `$BARO` |
| `stream off` | Вимкнути всі потоки |
| `cal show` | Калібрування рядками `cal set …`; збережений вивід можна надіслати назад як є |
| `cal set <поле> <значення…>` | Змінити одне поле в RAM. Діє одразу, без перезапуску фільтра; у flash потрапляє лише після `cal save` |
| `cal save` | Записати калібрування, температурну модель і налаштування у flash |
| `cal load` | Відкинути зміни й перечитати з flash |
| `cal erase` | Заводські значення, очищення flash, перезапуск фільтра |
| `thermal show` | Вивчена модель зсуву гіроскопа від температури |
| `thermal reset` | Забути вивчену модель. Фільтр при цьому перезапускається з початкового вирівнювання |
| `set mag <0\|1>` | Використовувати магнітометр. Зберігається через `cal save` |
| `reset` | Перезапустити фільтр з початкового вирівнювання |
| `reboot` | Перезавантажити Pico |
| `bootsel` | Перейти в USB-завантажувач для прошивання |

Частота `$ATT`, що діє на момент `cal save`, стає частотою після ввімкнення; за замовчуванням 50 Гц.

## Потоки

### `$ATT` — орієнтація

```text
$ATT,t_ms,qw,qx,qy,qz,roll,pitch,yaw,heading,bx,by,bz,tilt_sigma,heading_sigma,temp,flags
```

| Поле | Одиниці | Зміст |
|---|---|---|
| `t_ms` | мс | Час від старту Pico |
| `qw…qz` | — | Кватерніон зв'язана система → ENU |
| `roll`, `pitch`, `yaw` | ° | Кути Ейлера, порядок рискання–тангаж–крен |
| `heading` | ° | Компасний курс осі X, 0…360, за годинниковою від півночі |
| `bx…bz` | °/с | Оцінка зсуву гіроскопа |
| `tilt_sigma`, `heading_sigma` | ° | 1σ фільтра для нахилу (на вісь) і курсу |
| `temp` | °C | Температура кристала IMU, фільтрована |
| `flags` | hex | Бітова маска стану |

Біти `flags`:

| Біт | Маска | Назва | Зміст |
|---:|---|---|---|
| 0 | 0x001 | aligned | Орієнтацію ініціалізовано |
| 1 | 0x002 | coarse | Вирівнювання відбулося в русі, нахил ще сходиться |
| 2 | 0x004 | still | Плата у спокої, діє оновлення нульової швидкості |
| 3 | 0x008 | heading | Курс прив'язано до магнітного поля |
| 4 | 0x010 | acc-disturbed | Виявлено прискорення, вагу акселерометра знижено щонайменше вдесятеро |
| 5 | 0x020 | mag-disturbed | Виявлено магнітну заваду, вагу магнітометра знижено |
| 6 | 0x040 | mag-uncal | Магнітометр ігнорується: немає калібрування |
| 7 | 0x080 | saturated | Насичення сенсора або втрата вибірок за останню секунду |
| 8 | 0x100 | thermal | Триває температурний перехідний процес |
| 9 | 0x200 | recovery | Сторож розбіжності спрацював за останні 5 с |
| 10 | 0x400 | mag-stale | Понад секунду немає придатних вибірок магнітометра |

### `$RAW` — сирі дані IMU

```text
$RAW,seq,n,gx,gy,gz,ax,ay,az,temp
```

Усі поля цілі. Рядок містить **суми** `n` послідовних вибірок у відліках сенсора; `seq` — номер першої з них. Нумеруються всі вибірки IMU, незалежно від того, чи ввімкнено потік, тому за `seq` і `n` видно втрачені рядки, а час вибірки дорівнює `seq / odr_hz`.

Переведення у фізичні одиниці, з коефіцієнтами з `info`:

```text
гіроскоп, °/с   = gx / n · gyro_dps_per_lsb       (2000 / 2¹⁹)
прискорення, g  = ax / n · accel_g_per_lsb        (16 / 2¹⁹)
температура, °C = temp / n / temp_lsb_per_c + temp_offset_c
```

Дані некалібровані. При `n = 1` і 512 Гц потік становить близько 30 кБ/с.

### `$MAG` — сирий магнітометр

```text
$MAG,t_ms,mx,my,mz
```

Поле в мкТл в осях мікросхеми MMC5983MA з уже віднятим зсувом моста (SET/RESET), без калібрування. `t_ms` — середина перетворення. Близько 50 рядків за секунду.

### `$BARO` — барометр

```text
$BARO,t_ms,pressure_hPa,temp_C,altitude_m
```

Висота рахується за міжнародною барометричною формулою від рівня 1013,25 гПа. 25 рядків за секунду.

## Поля калібрування

Формат рядка: `cal set <поле> <значення…>`. Модель для кожного сенсора: `виправлене = матриця · (сире − зсув − поліном(T − T_ref))`.

| Поле | Кількість | Одиниці | Зміст |
|---|---:|---|---|
| `flags` | 1 | — | Біти: 1 гіроскоп, 2 акселерометр, 4 магнітометр, 8 температура гіроскопа, 16 температура акселерометра |
| `gyro_bias` | 3 | °/с | Зсув гіроскопа при `gyro_tc_tref` |
| `gyro_matrix` | 9 | — | Масштаб і неортогональність, по рядках |
| `accel_bias` | 3 | g | Зсув акселерометра |
| `accel_matrix` | 9 | — | Масштаб і перехресні зв'язки |
| `mag_bias` | 3 | мкТл | Hard iron |
| `mag_matrix` | 9 | — | Soft iron і поворот в осі IMU |
| `gyro_tc_tref`, `accel_tc_tref` | 1 | °C | Опорна температура полінома |
| `gyro_tc_x`, `_y`, `_z` | 3 | °/с на °C, °C², °C³ | Коефіцієнти полінома на вісь |
| `accel_tc_x`, `_y`, `_z` | 3 | g на °C, °C², °C³ | Те саме для акселерометра |
| `declination` | 1 | ° | Магнітне схилення, на схід додатне. 0 — курс від магнітної півночі |
| `mag_field`, `mag_dip` | 1 | мкТл, ° | Поле й нахилення, знайдені калібруванням; довідкові |

Фільтр використовує магнітометр лише тоді, коли у `flags` встановлено біт 4.

## Приклад сеансу

```text
> info
# fw=ins10-ahrs version=2.0.0 board=pico lib=2.0.0
# imu=ok clock=external odr_hz=512.000 measured_hz=511.987
# gyro_dps_per_lsb=0.00381469727 accel_g_per_lsb=3.05175781e-05 temp_lsb_per_c=132.48 temp_offset_c=25
# mag=ok mag_enabled=1 baro=ok
# att_rate_hz=50 raw_div=0
# last_reset=normal
# cal_flags=7 stored=1 thermal_count=1840
OK
> stream att 2
OK
$ATT,81234,0.999990,0.001200,-0.003100,0.002900,0.14,-0.36,0.33,89.67,0.2104,-0.1532,0.0871,0.03,0.21,31.42,00D
```

Числа в прикладі ілюстративні.
