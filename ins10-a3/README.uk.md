# INS10-A3: датчик орієнтації з 10 ступенями свободи для Raspberry Pi Pico

[Усі продукти](../README.uk.md) · [English](README.md)

![INS10-A3](images/module-iso.png)

Модуль 22,5 × 13,2 мм із 6-осьовим IMU (ICM-42688-P), 3-осьовим магнітометром (MMC5983MA) і барометром (LPS22DF) на одній шині SPI. Генератор 32,768 кГц тактує IMU рівно на 512 Гц. Підключіть модуль до Pico або Pico 2, прошийте безкоштовну прошивку — і отримаєте повну орієнтацію в 360° через USB. Потім покроково відкалібруйте його в безкоштовному додатку INS10 Studio на підставці, яку надрукуєте самі.

| | |
|---|---|
| Сенсори | Гіроскоп ±2000 °/с, акселерометр ±16 g (20 біт), магнітометр ±8 Гс (18 біт), барометр 260–1260 гПа |
| Вихід | Кватерніон, крен, тангаж, рискання, компасний курс, невизначеності, сирі дані; орієнтація до 200 Гц через USB |
| Фільтр | Розширений фільтр Калмана на 512 Гц з відстеженням зсуву гіроскопа, температурною компенсацією й адаптивним відкиданням прискорень і магнітних завад |
| Інтерфейс | SPI, 3,3 В, 8 дротів до Pico |
| Програми | Відкрита прошивка для Pico/Pico 2 і INS10 Studio для Windows |

Прошивка для Pico і Pico 2 (`.uf2`) та INS10 Studio для Windows (`.zip`) — на сторінці **Releases** цього репозиторію, у релізах, назви яких починаються з `ins10-a3`. Щоб щось змінити, зберіть їх із сирців: див. README [прошивки](firmware/README.md) і [INS10 Studio](studio/README.md).
